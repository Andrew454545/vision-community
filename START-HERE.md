# Start here

**Invited local Scene tester?** Follow [these short steps](LOCAL-SCENES-START-HERE.md)
with the kit supplied by the maintainer. This separate local preview requires no
service account. The hosted-service pause below still applies.

**Processing and online search are paused.** Please wait before downloading,
setting up or restarting VISION. Download links and setup steps will return when
the service is ready.

## Already have VISION?

Keep your VISION folder and private account code. If automatic processing is
still running, choose **Pause after batch** and leave it paused. Saved work and
previously earned credits are being preserved. You do not need to reinstall or
run the computer check during this pause.

## When the service opens

The release is intended for Windows PCs and Apple-silicon Macs. You will choose
**Scenes**, **Objects** or **Both**, save your private account code and run the
computer check before processing. Each mode needs its own approval.

## Need help?

- **Service unavailable?** This pause is expected; it does not mean your computer is broken.
- **Security warning?** Stop; do not change security settings.
- [Ask for help](https://github.com/Andrew454545/vision-community/issues/new?title=Help%20starting%20VISION). Describe the message; never share your account code.

Keep your code safe. Lost codes cannot be recovered.
