# Start here

**This is a preview. Regular processing and online search are not open yet.**
If the service says “not ready yet,” close VISION and try again when the project
maintainer announces that it is open. You do not need to fix your computer.

## 1. Download and open VISION

1. [Click here to download the Windows preview](https://github.com/Andrew454545/vision-community/releases/download/windows-starter-preview-20261001/VISION-Community-Windows.zip).
2. Open your **Downloads** folder. Find **VISION-Community-Windows.zip**.
3. Right-click it. Choose **Extract All**, then **Extract**.
4. Open the new folder, then the **VISION Community** folder inside it.
5. Double-click **Start VISION.cmd**. It may appear as **Start VISION**.
   In the small starter window, **type Y and press Enter** when asked to allow
   downloads and imagery for your chosen checks and work. The VISION page opens
   after the first download. Keep the small starter window open while you use VISION.

You do not need to install Python or Git, type commands, or have an
administrator password. The guided starter is for Intel or AMD Windows PCs.
Macs and Windows ARM computers do not use this starter.

## 2. Follow the four steps in the VISION window

1. **Set up this PC.** Click the button and wait. It downloads about 1 GB
   of files. This can take a while on a slow connection.
2. **Create an account.** Write down the private code or copy it somewhere safe.
   Choose **I have saved my code**. If you already have an account, choose
   **I already have an account** and enter that same code.
3. **Check this PC.** Click **Run the PC check** and wait for “PC approved.”
   You only need the short check; it tests 112 locations.
4. **Start helping.** Click **Start helping**. Leave the computer awake,
   connected to the internet, and the VISION window open.

To stop, click **Pause after this batch**. Wait for “Processing paused.”
To return later, open **Start VISION** again and use your saved account code.

## 3. Use your credits on the website

1. [Open the VISION website](https://vision-community.visioncommunity.workers.dev).
2. Choose **My account**. Enter the private code you saved in the PC app.
3. When search is available and you have **100,000 credit units**, describe the
   places you want, such as “a quiet road beside a lake.”
4. Choose **Run Search**, then **Download map**. Open the downloaded file in
   [map-making.app](https://map-making.app).

Only accepted results earn credits. Results waiting for a check do not count yet.
Your unused credits stay in your account. No name or email is needed.

## Something went wrong?

| What you see | What to do |
| --- | --- |
| “Not ready yet” or service unavailable | Come back later. Your computer is not the problem. |
| The ZIP opens instead of VISION | Choose **Extract All** first. Open the new folder and then **Start VISION**. |
| A download stopped | Check your internet connection. Open VISION and choose **Set up this PC** again. |
| Your account code is not accepted | Check for missing letters or extra spaces. Use the code from the PC app. |
| The PC check did not finish | Wait for it to stop, then try **Run the PC check** again. |
| A security message blocks the starter, or you need more help | [Ask the project maintainer for help](https://github.com/Andrew454545/vision-community/issues/new?title=Help%20starting%20VISION). Describe the message. Do not change security settings. |

**Keep your account code private.** Do not put it in a GitHub issue or send it
with a screenshot. If you lose it, the project cannot restore your credits.
