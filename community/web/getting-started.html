VISION COMMUNITY

Start here.

You do not need to know about computers. Follow these steps, one at a time.

This is a preview. Contributions and online search are not open yet.
If VISION says “not ready yet,” you have done nothing wrong. Come back when the project maintainer announces it is open.

1. Download and open VISION

Download the Windows preview
  1. Open your Downloads folder. Find VISION-Community-Windows.zip.
  2. Right-click the file. Choose Extract All, then Extract.
  3. Open the new folder, then the VISION Community folder inside it.
  4. Double-click Start VISION.cmd. Windows may show it as Start VISION. Keep the small starter window open.
  5. In the small starter window, type Y and press Enter when asked to allow downloads and imagery for your chosen checks and work. The VISION page opens after the first download.

No Python, Git, commands or administrator password needed. This starter is for Intel or AMD Windows PCs. Macs and Windows ARM computers do not use it.

2. Follow the four steps in the window

  1. Set up this PC. Click the button and wait. It downloads about 1 GB of files. A slow connection may take a while.
  2. Create an account. Write down your private code or copy it somewhere safe. Choose I have saved my code. Already have an account? Choose I already have an account and use that same code.
  3. Check this PC. Choose Run the PC check. Wait for PC approved. The short check tests 112 locations.
  4. Start helping. Click the button. Keep the computer awake, the internet connected and the VISION window open.

To stop: choose Pause after this batch. Wait for Processing paused. To return later, open Start VISION again and use your saved code.

3. Use your credits to find places

  1. Open the VISION website. Choose My account and enter the code you saved in the PC app.
  2. When search is available and you have 100,000 credit units, describe what you want. Try “a quiet road beside a lake.”
  3. Choose Run Search, then Download map. Open the file in map-making.app.

Each accepted scene location earns 1 credit unit. Results waiting for a check do not count yet. Your unused credits stay in your account.

Need help?

VISION says “not ready yet.”

The service is not open for contributions yet. Close VISION and come back later. Your computer is not the problem.

The ZIP opens instead of VISION.

Right-click the ZIP and choose Extract All first. Open the new folder, then the VISION Community folder and Start VISION.

A download stopped.

Check your internet connection. Open VISION and choose Set up this PC again.

My account code does not work.

Check for missing letters or extra spaces. Use the private code you saved in the PC app.

A security message blocks the starter.

Stop and ask the project maintainer for help. Do not change your security settings.

Ask the project maintainer for help. Describe the message you see.

Keep your account code private. Do not put it in a GitHub issue or a screenshot you share. If you lose it, the project cannot restore your credits.
