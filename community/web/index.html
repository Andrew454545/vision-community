Checking index Open the map site ↗
  1. Get an account. Click the gold button. Save the code it shows you — that is your only login.
  2. Help index. Choose Places, Objects, or Both, then click Start and leave this tab open. You get your own batch, so other people are not doing the same ones. Places count as 1 toward a search. Objects count as 10.
  3. Search. When the bar is full, press Search. Add the results to map-making.app, or copy them into the local Map Making App.

Places look around each panorama. Objects use the six-face cube, like VISION. Both does each in turn.

Faster (optional, needs the project files)

If you were given the project folder, paste this into Terminal after you have an account. Most people can ignore this and just click Start. Search also runs on your computer this way — there is no extra server to buy.

python3 -m community.local_search --prompt "red barn in snow" --recovery-code YOUR_CODE

Then add that JSON to a map: python3 -m community.send_mma result.json --new-map
