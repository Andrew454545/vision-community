      Index and search command

      Scenes and objects have to run in Terminal so they use the same indexers as VISION. Paste this after you have an account. The command keeps going until you stop it or the queue is empty.

      python3 -m community.vision_index --pace slow --recovery-code YOUR_CODE
      python3 -m community.object_index --search --prompt "red barn" --confidence balanced --recovery-code YOUR_CODE

      Scene search uses python3 -m community.vision_index --search, the same four-view search as VISION. Object search uses python3 -m community.object_index --search, the same object search as VISION. Then add the JSON to a map: python3 -m community.send_mma result.json --new-map
