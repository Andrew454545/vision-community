    Contribute

    Index on this computer the same way VISION.app looks at a location: four compass Street View for scenes, a six-face cube for objects. Imagery is not saved. One search costs 100,000 scene units (or 10,000 object units). No trial, no owner bypass. The CLI processes 16/64/128 scene locations per lease; this tab is limited to 1/4/8 because it still proxies thumbnails.

    python3 -m community.contribute --url https://vision-community.visioncommunity.workers.dev --lane scene --pace medium --recovery-code YOUR_CODE

    After you are invited to the private repository, install Pillow and run that command. The recovery code is saved to ~/.config/vision-community/session.json so later runs can omit it. Ctrl+C releases the exclusive lease.
