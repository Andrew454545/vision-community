# Help test VISION

We need one Windows 11 Intel/AMD PC and one Apple-silicon Mac. A fresh standard
user account on an existing computer is enough to begin; do not erase it.
Someone who does not normally use technical tools should try the setup too.

## Before starting

The maintainer will send a **signed test download**, its expected publisher and
an invitation. Wait for those. Keep normal Windows/macOS security protections
enabled. Stop and report an unexpected publisher or security warning.

The maintainer checks the downloaded file's signature and checksum and records
the computer's operating system, processor, memory and available storage.
These are installation checks, separate from the seven-day processing test.

## Try these steps

1. Download and open VISION. Follow the setup on screen without using a terminal.
2. Choose **Scenes** and finish the computer check. Save your recovery code
   privately. Let one invited batch finish; check that its earned searches appear.
3. Search with earned credit. Close and reopen VISION; recover that same search
   and confirm you were not charged again.
4. Enable automatic processing. Try Pause and Resume and the daytime/nighttime
   settings. Close the window and check that work can continue in the background.
5. Restart, sign back in, and reopen VISION. Then try sleep/wake and a brief
   internet outage. Your saved work and credit should remain; work should resume
   when the computer is awake, signed in and online.
6. With the maintainer's next invitation, repeat the processing and search checks
   for **Objects**, then **Both**. Each choice must pass its own computer check.
7. Install the maintainer's next signed update. Check your work, settings and
   credit, then use VISION's removal option. Reinstall and recover your account.

Ask for help at the first confusing instruction. Do not fix a problem by turning
off security or installing extra tools. Keep failure reports; they help us fix it.
Sleeping or switched-off computers cannot process locations.

## Tell us what happened

Send the maintainer your computer type, chosen mode, step reached and what you
expected versus what happened. Share reports through the agreed private channel.
Do not post recovery codes, identity documents, personal folders or location data
in a GitHub issue. A screenshot of unclear wording is useful after hiding those.

## Maintainer record

For each of the six OS/mode combinations, retain: exact candidate revision and
download SHA-256; signature/publisher/notarization assessment; OS/architecture
and standard-user state; qualified runtime/model/policy pins; real admission and
publication IDs; earned-credit balance before/after; original paid reply and free
recovery receipt; interruption/update/removal outcome; private failure/report
pins; and the tester's confirmation that no terminal or security exception was
needed. Record **not run**, **passed** or **failed** for every step, including
keyboard access and readable instructions. A maintainer-guided success does not
replace an unaided beginner walkthrough or the full accepted-work soak.

No tester result is recorded yet. Hosted Object qualification and trusted signed
downloads must be available before their dependent checks can pass. Follow
[platform acceptance](PLATFORM_ACCEPTANCE.md) and
[production acceptance](PRODUCTION_ACCEPTANCE.md).
