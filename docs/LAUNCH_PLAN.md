# Launch plan — 9 October 2026

**Not ready for public contributions yet.** These five exit gates define the
required first release: Windows and Mac, Scenes, Objects and Both, online
search, banked credit and unattended local work. Improvements beyond these
gates belong in follow-up work; “perfect” is not a measurable release test.

| Exit gate | Work to finish | Evidence required to close it |
|---|---|---|
| Trusted contributions | Finalize measured Scene/runtime policies; connect Object qualification, quarantine and native auditing to publication. Bind official Gen4 Objects to trusted server assignments and real quality authority. | Fresh qualified contributions in both lanes from Windows and Mac; incorrect or unqualified work refused; retries award credit once. |
| Earned-credit search | Publish only accepted contributor indexes, serve both native search modes and settle online searches against banked credit. Resolve early-user pricing without fake contributions. | A search paid with genuinely earned credit; exact retry/recovery without another debit; every result belongs to current authorized publication. |

No assumption that a powered-off or sleeping computer can compute. |
| Beginner downloads | Pin native/model assets, sign and package both platforms, and complete clean-device setup/update/removal and a nontechnical walkthrough. | Genuine signed Windows/Mac downloads; clean-device tests of Scenes, Objects and Both; one simple setup path. |
| Production operations | Exercise complete isolated storage/secret recovery, privacy fences, post-backup credit reconciliation, realistic search capacity and an enforceable spending limit. | Provider readback and retained recovery/load results; deleted data remains deleted, credits reconcile and limits fail safely. |

## Decisions made

- Preserve Andrew's verified model, geometry and ranking behavior. Byte equality
  across platforms is not required when a measured policy explicitly permits
  a numerical difference. No broad Object tolerance is inferred from three
  saved locations.
- Keep small resumable jobs. Unattended Object batches default to one location;
  independent Object audits have a hard four-location/900-second ceiling.
  Larger failed jobs are not made successful by extending their old deadlines.
- Keep computation independent of Codex. Automatically resume when the computer
  is awake and the user is signed in; clearly explain pauses and recovery.
  New setup paths consistently default to medium 06:00–00:00 / maximum
  00:00–06:00 scheduling. Existing saved custom schedules remain explicit.
- Keep official coverage, model execution, runtime qualification and financial
  settlement as separate checks. A valid file format cannot stand in for them.
- Use GitHub for source/releases and confirmed Community Cloudflare resources
  for private state and contributed indexes. Do not publish the reference corpus.
- Do not spend more on GitHub Actions. Use existing private toolchains and local
  Mac handoffs, preserve failures, and include `[skip ci]` in development commits.

## What is already established

Scene integration has eight genuine staging publications and eight earned units,
with replay protection. Hosted native Scene search and one-time payment were
also tested using a separate labeled disposable balance. That does **not** yet
prove payment from a full genuinely earned search balance.

The full identical-input Scene matrices are complete on Windows and Mac.
The recent Object packet contains three distinct cross-platform locations with
matching detection selections/PQ codes and small numerical differences. Official
Gen4 importing has separate real staging evidence. Delivery recovery, privacy
restore verifiers, guided platform controls and installer source checks are
implemented and tested. Keep their exact limits in
[PRODUCTION_ACCEPTANCE.md](PRODUCTION_ACCEPTANCE.md).

The new [native Object auditor](NATIVE_OBJECT_AUDIT.md) supplies the previously
missing full recomputation component. Its guard tests and real Windows runtime
contract check do not close hosted qualification or accepted Object work.

## External resources, not engineering approval

No further owner-side engineering sign-off or Actions budget is requested.
Legitimate signing-provider enrollment/identities and genuine clean Windows/Mac
test computers with a nontechnical tester remain unavailable. The prepared
GitHub `signing` environment is empty. Follow
[SIGNING-ACCOUNT-SETUP.md](SIGNING-ACCOUNT-SETUP.md); never paste credentials into
chat or disable operating-system protections.

There is no defensible completion date while those resources are missing.
Once admission works, the accepted-work soak itself requires at least seven
days and can run alongside packaging, recovery and capacity validation.
