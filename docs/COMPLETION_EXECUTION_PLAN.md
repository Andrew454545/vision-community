# Finish VISION Community

Owner request, 9 October 2026: Geonections should drive this project to a working
public release as quickly as the existing [five launch gates](LAUNCH_PLAN.md)
allow. This is their execution order, not a new feature list. The complete
release still covers Windows and Mac, Scenes, Objects and Both, banked-credit
online search and unattended processing. The entire corpus does **not** need
to be indexed before users can start contributing.

## Authority and working rules

Geonections owns routine engineering decisions: implementation, supported
profiles, measured tolerances, batching, sustainable early-user pricing, test
design, ordering and rollout preparation. Choose, briefly document the reason,
implement and continue. Andrew accepts the reported findings within their
recorded limits; another owner-side findings review is not a dependency.
Existing public-release gates remain in force.

Use the already authorized accounts/resources for tested migrations, deployment
and release when their prerequisites and gates pass; another routine engineering
permission request is not needed. Missing legal identities or an actual approval
rejection still need the specific human resource/action identified below.

Reuse completed evidence. Rerun checks when a change affects them, a failure
remains unresolved or a new measurement is needed. Do not repeat full Mac
calibration matrices or postpone integration with speculative features. Commit
and push concrete checkpoints with `[skip ci]`. Preserve the Actions spending
hold, required checks and branch protections; use existing private toolchains.
Never access `geonections-images`. Keep sources, private exports, credentials,
imagery and reference artifacts in the private handoff.

Signing enrollment, new billing commitments, missing private material and clean
test devices are resource dependencies. Send exact requests through the existing
coordination/private handoff, then continue independent work. Where automatic
approval has rejected a private export or Google lookup, preserve the rejection
and request the precise authorized payload/destination. Do not evade it or
repeatedly ask for general access.
