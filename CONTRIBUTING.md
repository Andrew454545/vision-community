# Help with VISION

**Want to process locations?** Follow [Start here](START-HERE.md).
If you get stuck, tell the person who invited you which step failed and what the message said.
Send reports and logs privately.

**Found a bug?** [Report a problem](https://github.com/Andrew454545/vision-community/issues/new/choose).
Do not post account codes, API keys or private result ZIPs.

**Contributing code?** Use the [current implementation branch](https://github.com/Andrew454545/vision-community/tree/codex/windows-production-readiness)
and read its [AGENTS.md](https://github.com/Andrew454545/vision-community/blob/codex/windows-production-readiness/AGENTS.md).
Run a focused local check for your change. Keep Google Street View tests, old jobs
and cloud services paused. Avoid GitHub Actions; development commits use `[skip ci]`.
